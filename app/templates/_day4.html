🔥 День 4 — Температура

Один и тот же запрос с разными значениями temperature

Temperature управляет вариативностью генерации модели. В этом эксперименте один и тот же запрос отправляется с разными значениями temperature.

Этот текст будет отправлен без изменений во всех трёх температурных экспериментах.

Temperature = 0

Минимальная вариативность. Обычно ответы более предсказуемы и консервативны.

Значение по заданию: 0

temperature — параметр API, влияющий на случайность выбора следующих токенов. Низкая temperature обычно делает ответы более предсказуемыми и консервативными. Средняя даёт баланс между стабильностью и вариативностью. Высокая может увеличить разнообразие формулировок, но снизить стабильность и точность. Эффект вероятностный. Temperature не делает модель умнее и не изменяет её знания.
max_tokens ограничивает максимальную длину генерации. Для корректного сравнения температур рекомендуется использовать одинаковое значение во всех трёх запросах.
stop задаёт последовательность, при появлении которой API прекращает дальнейшую генерацию. Для чистого сравнения temperature рекомендуется оставить stop одинаковым во всех трёх запросах.
