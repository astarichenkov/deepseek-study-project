День 3 — Разные способы рассуждения

Одна задача решается через DeepSeek API четырьмя способами — результаты сравниваются.

Эта задача используется всеми четырьмя способами. Измените её — и задача сменится для всех способов.

Общие параметры API

токенов
Что делает: ограничивает длину генерируемого ответа.
Механизм API: параметр max_tokens.
Важно: токен ≠ слово и ≠ символ. Слишком малый лимит может обрезать рассуждения; при исчерпании лимита finish_reason может стать "length".
Что делает: stop задаёт последовательность, при появлении которой API прекращает дальнейшую генерацию.
Механизм API: параметр stop — если пусто, не отправляется.
Внимание: неудачная стоп-последовательность может преждевременно оборвать рассуждение. Используйте различимый маркер (минимум 4 символа с буквой/цифрой).

Правильный ответ для демонстрационной задачи:
Борис — понедельник · Виктор — вторник · Анна — среда.
